TrimTrace.TrimTrace — Module
TrimTrace

Records the concrete call signatures a package's test suite makes into its public API and checks that they compile under juliac --trim=safe.

record_and_check runs the whole pipeline, and write_ci_workflow sets it up as a GitHub Actions job. The steps are:

  1. record runs the test suite under --trace-compile and --trace-dispatch and keeps the signatures of calls into public names of the package (positional, keyword and constructor calls, and calls to objects of its public types).
  2. uncovered lists the public names no recorded call reaches.
  3. check marks every signature as a trim entry point, compiles them with JuliaC, and reports the verifier errors per signature.

TrimTrace.TrimCheckResult — Type
TrimCheckResult

The outcome of check.

  • compiled: true when juliac compiled the entry file.
  • errors: the verifier reports that are not allowed.
  • allowed: the verifier reports covered by the allowlist, or value-dependent with allow_value_dependent = true.
  • signatures: the signatures that were checked.
  • log: the path of the full juliac output.

Use passed to decide the outcome.

TrimTrace.TrimError — Type
TrimError

One error or warning reported by the trim verifier.

  • kind: :error or :warning.
  • message: the verifier's description, including the unresolved statement.
  • entry: the signature the problem was reached from, as the report prints it, such as MyPkg.f(::Int64; k::Symbol). Without a stack trace it is the callee of the unresolved statement.
  • value_dependent: true when the unresolved statement involves a value used as a type (::DataType, Val(x), Type{T} where T). Such calls usually resolve when the argument is a compile-time constant, which a recorded signature cannot express. In a check result it is also required that the signature passes such a value (a DataType, Symbol, Type{T}, ...), since otherwise the value comes from inside the package and every caller hits the error.

TrimTrace.check — Method
check(pkg::Module, sigs; allow = [], allow_value_dependent = false, project = nothing,
      workdir = mktempdir(), julia_args = String[]) -> TrimCheckResult

Compile the signatures sigs with juliac --trim=safe and parse the verifier output.

Arguments
  • pkg::Module: the package whose signatures are checked.
  • sigs: the signatures as Tuple{...} expressions, as returned by record.
Keywords
  • allow = []: known failures. Each entry is a String equal to a signature as the report prints it (for example "MyPkg.f(::Int64; k::Symbol)") or a Regex matched against it. It can also be the path of a file with one entry per line (# starts a comment), where a line written as r"..." is a Regex, as in r"^MyPkg\.g\(.*kind::DataType".
  • allow_value_dependent = false: allow every report tagged value-dependent (see TrimError), which usually only fails because the recorded signature cannot express a constant argument.
  • project = nothing: the project juliac compiles in. With nothing, a project holding only pkg and the packages the signatures reference is generated in workdir, which keeps juliac from instantiating unrelated test dependencies.
  • workdir = mktempdir(): the directory for the entry file, the generated project, juliac.log and signatures.txt (the checked signatures as the report prints them). It is created if missing.
  • julia_args = String[]: arguments passed to the Julia process that compiles the image.
Returns

A TrimCheckResult; use passed to decide the outcome.

Throws
  • ArgumentError: sigs is empty, since an empty entry file compiles and would pass a check that tested nothing.
Examples
julia> using TrimFixture  # the demo package in test/fixtures

julia> sigs = record(TrimFixture; project = pkgdir(TrimFixture));

julia> check(TrimFixture, sigs; project = pkgdir(TrimFixture))
TrimTrace check failed: 1 errors (0 value-dependent), 0 warnings, 0 allowed
  1 x TrimFixture.unstable(::Int64)
Signatures checked: 6 (listed in /tmp/jl_JzYP0W/signatures.txt)
Full juliac output: /tmp/jl_JzYP0W/juliac.log

julia> allow = ["TrimFixture.unstable(::Int64)"];

julia> passed(check(TrimFixture, sigs; allow, project = pkgdir(TrimFixture)))
true

TrimTrace.record — Method
record(pkg::Module; project, test_file, exclude = Symbol[], abstract_params = false,
       julia_args = String[]) -> Vector{Expr}

Run the test suite of pkg with tracing on and return the public signatures it called.

The test file runs in a fresh Julia process with --trace-compile and --trace-dispatch. A traced call is kept when its callee is a public name of pkg (a function, a constructor, or an object of a public type) and every argument type is concrete.

Arguments
  • pkg::Module: the package under test.
Keywords
  • project: the test environment. Defaults to the package's test directory. A package that declares its test dependencies with [extras] and [targets] instead of a test/Project.toml gets a generated test project holding the package, its dependencies and those test dependencies.
  • test_file: the file to run, by default test/runtests.jl.
  • exclude = Symbol[]: names whose calls are dropped.
  • abstract_params = false: keep signatures whose argument types have an abstract type parameter, as in Vector{Any}. Such containers come from tests passing mixed values and dispatch dynamically on their elements, which a trimmed caller would avoid.
  • julia_args = String[]: arguments passed to the child process before the test file.
Returns

The recorded signatures, sorted and deduplicated.

Notes

Failing tests only produce a warning, since the calls they made are still valid signatures. Calls whose types are defined in the test files are dropped, and a trailing Vararg{A} is recorded as a single A.

--trace-compile alone misses a call whose specialization was already compiled as the callee of an earlier call; --trace-dispatch still logs it as long as the test makes the call dynamically, as top-level test code does. A call made from inside a compiled test helper function with inferable argument types is not dispatched dynamically and can be missed.

Examples
julia> using TrimFixture  # the demo package in test/fixtures

julia> record(TrimFixture; project = pkgdir(TrimFixture))
6-element Vector{Expr}:
 :(Tuple{TrimFixture.Scaler, Int64})
 :(Tuple{Type{TrimFixture.Box}, Int64})
 :(Tuple{Type{TrimFixture.Scaler}, Int64})
 :(Tuple{typeof(Core.kwcall), NamedTuple{(:factor,), Tuple{Int64}}, typeof(TrimFixture.scaled), Int64})
 :(Tuple{typeof(TrimFixture.stable), TrimFixture.Box})
 :(Tuple{typeof(TrimFixture.unstable), Int64})

TrimTrace.record_and_check — Method
record_and_check(pkg::Module; allow = [], allow_value_dependent = false,
                 workdir = mktempdir(), test_project, test_file, exclude = Symbol[],
                 abstract_params = false)
    -> TrimCheckResult

Record the public calls the test suite of pkg makes and check them with juliac --trim=safe, in one step.

This is record followed by check, so the checked signatures are those of the current tests.

Arguments
  • pkg::Module: the package under test.
Keywords
  • allow = []: known failures, as for check.
  • allow_value_dependent = false: passed to check.
  • workdir = mktempdir(): passed to check. It ends up holding signatures.txt, the generated entry.jl and juliac.log, for looking at what was checked.
  • test_project: the test environment, passed to record as project.
  • test_file: passed to record.
  • exclude = Symbol[]: passed to record.
  • abstract_params = false: passed to record.
Returns

A TrimCheckResult; use passed to decide the outcome.

Throws
  • ArgumentError: the tests made no public call of pkg.
Examples
julia> using TrimFixture  # the demo package in test/fixtures

julia> result = record_and_check(
           TrimFixture;
           allow = ["TrimFixture.unstable(::Int64)"],
           test_project = pkgdir(TrimFixture),
       );

julia> passed(result)
true

julia> length(result.signatures)
6

TrimTrace.write_ci_workflow — Function
write_ci_workflow(pkg_path = pwd(); path, julia = "1", allow = "test/trim-allow.txt",
                  allow_value_dependent = false) -> String

Write a GitHub Actions workflow that runs record_and_check on every push and pull request.

The job records the test suite and compiles the recorded calls with --trim=safe, so every run checks the calls of the current tests. It fails when passed is false.

Arguments
  • pkg_path = pwd(): the root of the package, holding its Project.toml.
Keywords
  • path: the workflow file, by default .github/workflows/TrimTrace.yml in pkg_path.
  • julia = "1": the Julia version the job runs (1.13 or later).
  • allow = "test/trim-allow.txt": the allowlist file, relative to pkg_path. The job uses it only when it exists.
  • allow_value_dependent = false: passed to record_and_check by the job.
Returns

path.

Notes

The job installs TrimTrace and the package in an environment of their own and instantiates test/Project.toml for record, which runs the tests there.

Examples
julia> using TrimFixture  # the demo package in test/fixtures

julia> path = write_ci_workflow(pkgdir(TrimFixture); path = tempname());
[ Info: Wrote the TrimTrace CI workflow to /tmp/jl_Ze9ulQjm3U

julia> strip(only(filter(contains("record_and_check"), readlines(path))))
"result = record_and_check(TrimFixture; allow)"
